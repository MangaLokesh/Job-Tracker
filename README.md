# 💼 JobTrack – Job Application Tracker

JobTrack is a React-based web application that helps users organize and track their job applications in one place. Users can add, edit, delete, and manage applications based on their current status.

## ✨ Features

- 📊 **Dashboard:** View total applications, applied jobs, interviews, and offers.
- ➕ **Add Applications:** Record company name, job role, application date, and status.
- ✏️ **Edit Applications:** Update existing application details.
- 🗑️ **Delete Applications:** Remove applications with confirmation.
- 🎯 **Status Filtering:** Filter applications by Applied, Interview, Offer, or Rejected.
- 🏷️ **Status Badges:** Identify application statuses using different colors.
- 💾 **Local Storage:** Automatically save applications in the browser so they remain available after refreshing the page.
- 📱 **Responsive Design:** Use the application on desktop and mobile screens.

## 🛠️ Tech Stack

- ⚛️ React.js
- 🟨 JavaScript (ES6+)
- 🌐 HTML5
- 🎨 CSS3
- 💾 Browser Local Storage
- ⚡ Vite

## 🚀 Getting Started

### 📋 Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git

### 📥 Installation

**1. Clone the repository**

```bash
git clone https://github.com/MangaLokesh/JobTrack.git
```

**2. Navigate to the project directory**

```bash
cd JobTrack
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local URL** displayed in your terminal to use JobTrack.

## 📖 How It Works

1. 📝 Add a job application with the company name, role, date, and status.
2. 📋 View all applications in the dashboard table.
3. ✏️ Edit or delete applications whenever needed.
4. 🎯 Filter applications by their current status.
5. 🔄 Refresh the browser without losing saved applications.

## 💾 Data Storage

JobTrack uses browser Local Storage to persist application data. The project currently does not use a backend server, user authentication, or a cloud database. Data is stored locally in the browser.
